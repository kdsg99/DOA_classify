# v4 分类尺：按「解题所需的思维动作」分类，并检验策略是不是在诱导这种思维

数据：同一批 2801 行 / 683 任务 / 5 策略。策略定义取自 `config/prompts/strategies.py`。

## 1. 分类尺（11 个思维动作，多标签 + primary）

- **检索回忆**（T1_RECALL）：答案、事实、定义已经存在，只需准确调出并按原样使用，几乎不需要加工或推导。
- **链式推演**（T2_CHAIN）：必须一步一步推导或计算（数值/符号/逻辑链），中间任何一步错都会导致结果错。
- **分解规划**（T3_PLAN）：目标复杂或步骤众多，必须先把任务拆成子任务、安排好顺序与优先级，再逐项完成。
- **约束对齐**（T4_CONSTRAINT）：必须同时满足多条明确而硬性的要求（字段/格式/字数/接口/规则），违反任何一条就算失败。
- **信息整合**（T5_INTEGRATE）：关键信息分散在长材料或多个片段里，必须合并、去重、消解冲突之后才能用。
- **校验纠错**（T6_VERIFY）：输入或已有产出中很可能藏着错误/不一致，必须主动检查并找出来改正。
- **抗扰判断**（T7_RESIST）：题面含错误前提、诱导线索或反直觉陷阱，必须识破它并重新选对方向，而不是顺着错前提往下答。
- **探索发散**（T8_EXPLORE）：没有唯一答案，必须自己设定方向、比较多种方案或生成新的想法。
- **换表征**（T9_REFRAME）：必须换成另一种表示或视角（形式化、图示、类比、单位/坐标系变换）才能推进。
- **语用改写**（T10_PRAGMA）：内容是给定的，必须按受众、语气、体裁或语言重新组织表达。
- **长程一致**（T11_SUSTAIN）：输出很长，必须在全篇维持结构、风格、事实与口径一致，不能中途漂移。

## 2. 策略想诱导什么思维（假设）

- **PRESSURE** → 目标动作 ['链式推演']；否认结果+推责+期望压力（严厉）→ 逼模型把活重做一遍 → 应在“必须自己一步步推/算”的题上收益最大
- **ENCOURAGE** → 目标动作 ['探索发散', '长程一致']；认可已有努力与优点 → 促使在原有思路上继续展开、写更多 → 应在“要展开、要写长”的题上有效
- **CRITICAL** → 目标动作 ['校验纠错']；判定为不合格且不解释原因 → 逼它重组/自查 → 应在“要查错、要重组”的题上收益最大
- **MISLEADING** → 目标动作 ['抗扰判断']；自信而权威的错误线索 → 检验能否坚持正确方向 → 应在“抗扰判断”类题上损失最大（被带走）
- **HEURISTIC** → 目标动作 ['探索发散', '换表征']；表达自己的怀疑+中立+不给提示 → 逼它自主探索多路径 → 应在“无唯一解/需换路子”的题上收益最大

## 7. 怎么读这些数

- 单元格值 = 该策略在「需要这种思维」的题上，提升率比它在其余题上高/低多少（pp），且已在每个评测族内部对比过，所以读作：**该策略对这种思维题型有没有额外加成**（已经扣掉族差异）。
- 55 个单元格里最大效应 ±(9~15)pp，最小置换 p≈0.05，**没有一个能过 FDR<0.05**；下面结论按「提示性」看待。
- high/low 是二值化产物，丢掉了分差幅度；下一版建议改用**连续分差 Δscore** 作因变量（同样族内平衡），灵敏度会明显更高。

## 8. 结论

1. **「策略=诱导某种思维」方向对，但强度有限。** CRITICAL 在「抗扰判断」(+10.6pp)、「校验纠错」(+15.9pp raw) 上居首，HEURISTIC 在「换表征/语用改写」上居首，方向与策略设计一致；但 PRESSURE 只在「链式推演」上保持不掉队（它全局都强，没有专属舞台），ENCOURAGE 没有明显的专属题型。
2. **本批数据最强的一句话**：五个策略的增益高度重叠（PRESSURE 几乎覆盖其余四家的全部增益），真正拉开差距的只有两件事——**强弱**、以及**题目属于哪个评测族**（族维度的交互 z=+6.2，远高于任何内容/思维分类尺）。
3. **要让「所需思维」这把尺子真正立功**：(a) 改用连续分差做因变量；(b) 每个单元格需要更多任务（现在 n≈30~250）才能把 ±10pp 做实；(c) 让「链式推演」「抗扰判断」这类思维要求能跨评测族出现，而不是与某个数据集绑定。
