# 难度校正（Difficulty Correction）：方法与诊断说明

*Thinking-type × re-ask strategy 分析中的难度混杂处理*

本文件说明 Figure 2 / Figure 3（以及 `out/cells_3dims.csv` 中的 `std`、`std_fam` 两列）所采用的
难度校正做法，包含估计量定义、识别假设、诊断、敏感性分析与局限。所有数值可由
`tt3_analysis.py` 复现。

---

## 1 问题：为什么"再问一次"的效果不能直接比

设一个任务在前一轮作答中的得分为 `p`（0–100，min-max 归一化），未施加任何策略的这次作答记为
"plain"，对同一任务施加策略 `s` 后的作答得分记为 `p'`。我们关心的是每个 *(策略, thinking type)*
单元格的效果

    Δ = 100 · (p' − p)                       (单位：pp)

以及"该策略在这个 thinking type 上相对擅长 / 不擅长"的画像。直接对各格取 Δ 的算术平均（记作 `raw`）
会同时混入三种与策略无关的成分：

**(i) 天花板饱和。** Δ 的上界是 `100 − p`，下界是 `−p`。当 `p = 100` 时 Δ ≤ 0：一个已经满分的任务
在被"再问一次"之后只可能掉分。各策略的饱和行占比差异极大（表 1 第 3 列）：PRESSURE 6.6%，CRITICAL
20.2%，MISLEADING 23.2%，ENCOURAGE 26.5%，HEURISTIC 36.1%。不校正时，这些行给"话多的策略"带来了
系统性的负向惩罚，而这与策略本身的质量无关。

**(ii) 头寸异质性。** Δ 的大小在 `p` 上并不均匀：`p` 很低时，模型本来就做错，再问一次带来的边际
提升最大；`p` 已经很高时几乎没有提升空间，甚至因为改写而掉分。因此同一格内 Δ 的期望是 `p` 的函数
`μ_s(p)`，而非一个常数。

**(iii) 构成混杂。** thinking type 是任务内容的标签，与任务难度高度相关：数学推理类（L1-R、L2-R）
的基线 `p` 明显低，而格式类（L1-F、L2-F）基线极高（多为 0.92 / 0.72 附近）。此外，同一 type 在不同
策略下的行集合也不完全相同（`mode` 与任务族的可用性差异）。于是"哪个 type 效果好"的跨格比较，实
际上在比较"哪些格子恰好装的是难题"。

这三种成分合在一起的效果是：`raw` 列系统性高估"策略间的画像差异"，并且在策略之间制造了本不存在的
优劣排序（例：HEURISTIC 的 raw 均值 −24.3 pp，其中约 36% 的行来自"只能掉分"的饱和任务）。

## 2 记号

| 记号 | 含义 |
|---|---|
| `s ∈ {PRESSURE, CRITICAL, ENCOURAGE, MISLEADING, HEURISTIC}` | 策略 |
| `t ∈ T`，`|T| = 12` | thinking type = 操作层级 L1/L2/L3 × 干预对象 K/R/E/F |
| `p_i` | 第 i 行的基线（plain / no-strategy）得分，0–100 |
| `Δ_i` | 第 i 行的得分变化，pp |
| `b(p) ∈ {0,1,2,3}` | 基线分箱函数，见 §3.2 |
| `w_b` | 参考难度混合（reference mix），`Σ_b w_b = 1` |
| `m_{s,t,b}` | 单元格 (s,t) 中落入箱 b 的行的 Δ 均值 |
| `cov_{s,t} = Σ_b w_b · 1[箱 b 在 (s,t) 中非空]` | 该单元格对参考混合的覆盖度 |

样本：2801 行 *(策略, 任务)* 观测；落在头寸带内的 1954 行。单元格行数 min / 中位数 / max =
2 / 36.5 / 204。

## 3 校正方法

### 3.1 第一步：头寸带截断（headroom band）

只保留 **5 ≤ p_i ≤ 95** 的行。理由：`p = 100` 的行没有任何上行动空间，`p ≈ 0` 的行几乎必然做错、
Δ 的方差极小且下界紧贴 0，二者都使 Δ 的期望与"策略质量"脱钩。带内行占比因此成为样本量的限制项：
PRESSURE 84.1%、CRITICAL 73.7%、MISLEADING 70.7%、ENCOURAGE 67.9%、HEURISTIC 59.1%。

**这是本方法的主要代价**：HEURISTIC 有 40.9% 的行被截掉，其带内样本最小；同时"截掉饱和行"意味着
本方法不再回答"对一个已经做对的任务再问一次会怎样"，而只回答"在还有提升空间的任务上，再问一次的
平均效果如何"。

### 3.2 第二步：难度分箱与参考混合

在带内按 20 pp 等宽分箱：

    b(p) = 0 : [ 5, 25)      b(p) = 2 : [45, 65)
    b(p) = 1 : [25, 45)      b(p) = 3 : [65, 95]

参考混合 `w` 取"所有带内行在四个箱上的边际分布"（跨策略、跨 type 合并）：

| 箱 | 基线 p | 权重 w_b |
|---|---|---|
| 0 | [5, 25) | 0.093 |
| 1 | [25, 45) | 0.068 |
| 2 | [45, 65) | 0.108 |
| 3 | [65, 95) | 0.731 |

即多数带内行落在 65–95 这一段"只剩余少量提升空间"的区间，这与"给一个已经答得不错的模型再问一次"
的实验场景一致。

### 3.3 第三步：直接标准化（direct standardization / post-stratification）

单元格取值定义为把该格各箱的 Δ 均值**重加权到统一的参考混合**上：

    Δ̂_{s,t} = Σ_b  w_b · m_{s,t,b}  /  Σ_{b ∈ B(s,t)} w_b        (＝ std 列)

其中 `B(s,t)` 是该格中非空的箱集合，分母 `cov_{s,t}` 即覆盖度。缺失的箱不参与（而不是补 0），因此
分母会随覆盖度缩小；本数据中 `cov` 最小值 0.731、中位数 1.000，没有任何单元格触发退化规则
（§3.6）。这在统计上就是**分层后标准化**：把每个格子的"难度构成"换成同一个反事实构成。

注意这是一个**参照系的选择**，而不是一个"真值"：它把"效果好"定义成"在参考混合这一难度构成下"的
效果。因此不同混合下的水平不可直接互比，只能在同一混合内比较策略与 type（见 §6 敏感性）。

### 3.4 第四步：评测族平衡（size balancing）

带内样本在评测族（MT-Bench / MATH-500 / FLASK-Chat / FLASK-Llama / FLASK-Qwen / WildBench）之间
分布不均，且族与任务体裁、评分方式耦合。因此再做一个"一族一票"的重平均：

    Δ̂^{fam}_{s,t} = (1 / |F(s,t)|) Σ_{f ∈ F(s,t)} Δ̂_{s,t|f}          (＝ std_fam 列)

其中 `Δ̂_{s,t|f}` 是把 §3.3 的公式单独用在族 f 的子样本上。`|F(s,t)|` 为 2–6。该步骤不改变单格的
难度构成（已由 §3.3 固定），只改变"格内由哪个族主导"的权重，防止某个 type 的结论实际上来自单一
benchmark。

### 3.5 第五步：基线居中（相对画像）

主图（Figure 1–3）画的是**相对画像**：每个策略减去它自己在 12 个 type 上的等权均值（一型一票）

    Δ̃_{s,t} = Δ̂_{s,t} − (1/|T|) Σ_{t'} Δ̂_{s,t'}                    (＝ *_rel 列)

于是 0 的含义是"这个策略在这个 type 上就它自己的平均水平"：正 = 相对擅长，负 = 相对不擅长。
参考视图（Figure 1L / 2L）画的是未居中的绝对水平 `Δ̂`。

### 3.6 退化规则与薄格

若 `cov_{s,t} < 0.5`（即该格只覆盖参考混合不到一半的质量），则放弃加权、退回该格的带内算术平均，
并在 `out/cells_3dims.csv` 中标记 `fallback = True`。本数据 0 个单元格触发。行数 `n < 15` 的格子
标记为 `thin = True`（L1-F 的多数格子，n 可低至 2），图上以"更淡的 bar + 红色 n"提示，其数值仅供
参考，不参与任何结论性排序。

### 3.7 参考口径（不作为主图）

`resid_lin` 为替代口径：对每个策略单独做 Δ 对 p 的 OLS 回归，取每格残差均值。它移除的是该策略自身
的"Δ–p 趋势"，因而连策略自身水平一起移除，会抹掉策略之间的水平差异（PRESSURE 与 HEURISTIC 的均值
都会被拉到 0 附近），故仅作为稳健性参考列保留在 CSV 中，不用于主图。

## 4 识别假设与解释边界

1. **分层内可交换性**：在同一难度箱内，各单元格的行在"策略效果"上没有残余系统性差异。分箱只有
   4 档，箱内仍可能有 `μ_s(p)` 的残余坡度（`p` 从 65 到 95 的变化不小）。这是最容易被违反的一条，
   也是敏感性分析（§6）里水平值随混合剧烈变化的直接原因。
2. **单一混杂**：本方法只调整了一个离散混杂因子（基线得分/头寸）。任务体裁、评分方式（人评 vs
   精确匹配）、语言等未进入调整集，只通过族平衡（§3.4）部分吸收。
3. **无测量误差**：`p` 与 `p'` 被当作精确值；实际上评分本身含噪，噪声在有界尺度上会向中心收缩。
4. **描述性而非因果性**：本方法输出的是"在给定参考难度构成下的平均差异"，是描述性调整，不做因果
   声明；策略之间不存在随机化，策略与任务集合的对应关系由数据收集决定。
5. **截断改变目标量（estimand）**：结论的适用范围是 5 ≤ p ≤ 95 的任务，不含已满分与接近零分的任务。

## 5 诊断

**(a) 阴性对照：PRESSURE。** PRESSURE 的设计意图是近乎无语义的重复，理应处处接近 0。原始口径给出
均值 +3.1 pp；校正后 +(−0.2) pp、SD 5.7、极差 19（表 3）。校正把它的"虚假正收益"（主要来自带内低分段
与饱和行的抵消关系）抹平，符合预期。

**(b) 校正的净效果（每策略对 12 格，一型一票）。** 见表 3：校正后非 PRESSURE 四家的 SD 明显收窄
（CRITICAL 15.8 → 10.6，HEURISTIC 19.4 → 12.7），而 ENCOURAGE / MISLEADING 基本不变（23.4 → 20.1，
19.0 → 20.2）——它们的画像主要由内容差异驱动，而非难度构成。这一差异本身说明：**难度构成只解释四家
中的两家**，其余两家的起伏是真实的任务内容交互（但也未通过 FDR，见前次结论）。

**(c) 覆盖度。** `cov` 中位数 1.000、最小 0.731，说明参考混合的四箱在每个格子里基本都能覆盖；退化
规则未被使用。

## 6 敏感性分析

对"参考混合"这一参照系做四组替换（每策略 12 格，一型一票；格式：均值 / SD / 极差，单位 pp）：

| 口径 | PRESSURE | CRITICAL | ENCOURAGE | MISLEADING | HEURISTIC |
|---|---|---|---|---|---|
| RAW（无校正） | +3.1 / 6.2 / 26 | −12.5 / 15.8 / 57 | −23.1 / 23.4 / 76 | −27.6 / 19.0 / 61 | −24.3 / 19.4 / 65 |
| A. 带 5–95，参考混合 w（当前） | −0.2 / 5.7 / 19 | −8.5 / 10.6 / 38 | −16.7 / 20.1 / 74 | −25.1 / 20.2 / 69 | −18.3 / 12.7 / 48 |
| B. 带 5–95，四箱等权 | +11.0 / 12.7 / 49 | +4.1 / 15.5 / 52 | −7.6 / 24.6 / 91 | −13.9 / 25.9 / 86 | −9.0 / 17.3 / 66 |
| C. 带 5–65，自混合 | +20.9 / 24.4 / 90 | +16.3 / 12.9 / 45 | +6.1 / 12.1 / 39 | +4.0 / 11.4 / 37 | +0.9 / 13.6 / 52 |
| D. 带 25–95，自混合 | −3.3 / 5.0 / 15 | −11.6 / 9.9 / 34 | −18.6 / 19.1 / 72 | −27.8 / 19.0 / 65 | −19.8 / 12.0 / 44 |

三点读数：

1. **水平值高度依赖参照系**。B / C 两个口径把权重压向低分段（5–65），此时所有策略都变成正收益，
   PRESSURE 从 −0.2 跳到 +11.0、+20.9。含义清楚：在难题上"再问一次"普遍有益，在接近满分的题上普遍
   有害；因此任何"这个策略值多少 pp"的说法都必须附带难度构成。
2. **排序的稳健部分**。当参照系偏向高分段（A、D）时，五家的次序稳定为 PRESSURE ≫ CRITICAL >
   HEURISTIC ≈ ENCOURAGE > MISLEADING（按均值），且 PRESSURE 的 SD 始终最小（5.0–5.7）。
3. **不稳健的部分**：C 口径下 PRESSURE 的 SD（24.4）反而最大，即"PRESSURE 是最平的那个"这一结论
   只在"高基线为主"的参照系下成立。这是本方法最重要的一条自我限制。

## 7 局限

- **格子粒度上限**：12 个 type、每策略 12 格，格内中位数 36.5 行，最薄格 n = 2。要稳定呈现 5 pp 级
  差异，按现噪声每格需 ≈100 行（前次分析结论），当前数据不满足。
- **策略近似替代**：五家策略两两 Δ 相关系数 0.66–0.93，校正不能制造它们在本不存在的"专长"差异。
- **分箱粒度**：4 档箱是"样本量 vs 残余坡度"的折中；箱内 `μ_s(p)` 的残余斜率会污染水平值。
- **族平衡不是聚类稳健标准误**：§3.4 只平衡权重，未对族做聚类方差估计，表中未给置信区间；若需要
  区间，应以族为聚类单位做 bootstrap（未在本次实现）。
- **截断代价**：HEURISTIC 丢掉 40.9% 的行，其带内结论对"该策略的适用域"最不具代表性。

## 附录 A 伪代码

    for s in strategies:
        D_s   = rows where strategy == s
        B_s   = [r in D_s if 5 <= r.p <= 95]
        for t in types:
            gb = [r in B_s if r.type == t]
            if len(gb) == 0: continue
            for b in bins(0..3):
                m[b] = mean(dpp of rows in gb with bin == b)
            w        = [w[b] for b in bins if m[b] is not None]
            cov      = sum(w)
            std[s,t] = sum(w[b] * m[b] for b in bins if m[b] is not None) / cov   if cov >= 0.5
                     else mean(dpp of gb)
            per_fam  = [ same standardization inside each family f of gb ]
            std_fam[s,t] = mean(per_fam)
        for t in types:                      # baseline-relative profile
            std_rel[s,t] = std[s,t] - mean_t'(std[s,t'])
