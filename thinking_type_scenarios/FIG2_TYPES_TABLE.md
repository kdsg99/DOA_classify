## 表 2 三维度合起来要求什么思考（逐型一句话）

写法：**（层级）做什么 + （对象）对什么 + （起点）从哪里出发**。

| type | 认知需求描述 | 主要失败模式 |
|---|---|---|
| L1-K | 从零出发，把问题命中的事实/知识点直接取出（单步） | 取不到、取错对象 |
| L1-R | 在已有题面或上一轮结果上，直接算出一个结果（单步计算，85.8 的高基线说明多数题已会做） | 算错、抄错条件 |
| L1-E | 在既有产出的基础上，直接生成/改一段内容（语气、措辞、长短） | 跑题、口吻不符 |
| L1-F | 从零把给定内容转成另一种格式，硬约束必须全部命中 | 漏项、格式越界（薄格 n = 2–3，仅供参照） |
| L2-K | 在既有信息上把多个来源整合成一个有条理的答案（先取后组） | 只罗列不整合、来源冲突未处理 |
| L2-R | 从零串联多步推导（无既有链条可承接），错一步全错 | 中途出错、步骤跳步 |
| L2-E | 从零搭出篇章结构：分段、顺序、衔接、详略 | 结构松、层次乱 |
| L2-F | 承接既有内容，把它重排成指定结构（表格/schema/模板） | 结构不成立、字段缺失 |
| L3-K | 从零对既有说法/自己刚给的结论做事实核验（需要外部锚点） | 没验、验错方向、跟着错 |
| L3-R | 承接一条正在进行的过程，做控制与修正（发现偏差并纠偏） | 没发现偏差、改了不该改的 |
| L3-E | 承接既有文本，保持风格/人设一致（改动要克制） | 风格漂移、越改越不像 |
| L3-F | 从零对照约束清单逐条校验并修复（约束满足度是唯一标准） | 漏条、修了一条破坏另一条 |

## 表 3 分布核对：三个维度彼此正交

- **维度 1（层级）**：L1 / L2 / L3 各 4 型。
- **维度 2（对象）**：K / R / E / F 各 3 型。
- **维度 3（起点状态）**：承接 6 型 / 从零 6 型，且在每个层级上**恰好 2 : 2**，在每个对象上为
  1–2 : 2–1 —— 即第三个维度不重新引入层级或对象上的不平衡。

| 维度1 \ 维度3 | 承接 | 从零 |
|---|---|---|
| L1 执行 | L1-R, L1-E | L1-K, L1-F |
| L2 结构 | L2-K, L2-F | L2-R, L2-E |
| L3 元认知 | L3-R, L3-E | L3-K, L3-F |

| 维度2 \ 维度3 | 承接 | 从零 |
|---|---|---|
| K 知识 | L2-K | L1-K, L3-K |
| R 推理 | L1-R, L3-R | L2-R |
| E 表达 | L1-E, L3-E | L2-E |
| F 格式 | L2-F | L1-F, L3-F |

正交性校验（Cramér's V，0 = 独立）：起点状态 vs 层级 = **0.00**；起点状态 vs 对象 = 0.33。
对照：头寸 vs 层级 = 0.41、vs 对象 = 0.58（故未采用为第三维）。
